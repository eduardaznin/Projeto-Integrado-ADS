# Projeto Integrador 2026: App de Apoio Camuflado

Protótipo acadêmico de aplicativo de apoio a mulheres em situação de violência doméstica, disfarçado de calculadora.

**Aluna:** Eduarda Zanin de Abreu (ADS, projeto individual)
**Disciplinas:** Desenvolvimento Móvel e Data Science

## Estrutura do repositório

- `app/`: aplicativo mobile (React Native + Expo)
- `api/`: back-end (Node.js + Express)
- `painel/`: painel web da delegacia (simulação)
- `data-science/`: análise de dados e modelo (Python)
- `docs/`: documentação e protótipos
- `USO_IA.md`: registro de uso de Inteligência Artificial

## Como rodar o app

```
cd app
npm install
npx expo start
```

Escaneie o QR code com o Expo Go.

## Aviso

Este é um protótipo acadêmico. Não substitui atendimento policial, jurídico, psicológico ou de saúde real. Todos os dados de teste são fictícios.

Em caso de emergência, ligue **190**. Central de Atendimento à Mulher: **180** (24 horas).
